Chapter 2 Variant Calling

Variant calling was performed at different analytical resolutions according to the sequencing platform and the capabilities of each tool. For 10x Genomics datasets, variants were identified at the pooled, cell-type, or single-cell level, whereas Smart-seq2 datasets were analyzed at the individual-cell level. Tool-specific preprocessing, calling parameters, filtering procedures, and output processing steps are documented in the following sections.

Analysis level Tools
10x pooled GATK; FreeBayes; SAMtools; VarScan2; Strelka2; Monopogen; scSNV; cellsnp-lite
10x cell type SComatic; cellsnp-lite; SAMtools; FreeBayes; VarScan2; Strelka2; Monovar
10x single cell Monopogen; scSNV; scAllele; cellsnp-lite
Smart-seq2 single cell GATK; SAMtools; FreeBayes; VarScan2; Strelka2; cellsnp-lite; scAllele; Monovar

2.1 GATK

GATK HaplotypeCaller detects SNVs and indels using local haplotype assembly and probabilistic genotyping.

The workflow included:

  • Preprocessing: Apply SplitNCigarReads to RNA-seq BAM files.
  • Variant calling and filtering

Reference: GATK (Genome Research, 2010)

    raw_vcf="${SAMPLE_DIR}/${sample}.vcf.gz"
    

    pass_vcf="${SC_BASE}/filter/${sample}_PASS.vcf.gz"

    if [[ ! -f "$raw_vcf" ]]; then
        echo "[WARN] Skip $sample: VCF not found"
        continue
    fi

    if [[ -f "$pass_vcf" && -f "${pass_vcf}.tbi" ]]; then
        echo "[SKIP FILTER] $sample"
        echo "[INFO] Kept sites: $(bcftools view -H "$pass_vcf" | wc -l)"
        continue
    fi

    echo "[FILTER] $sample"

    tmp_dir="${SAMPLE_DIR}/tmp_filter"
    mkdir -p "$tmp_dir"

    norm_vcf="${tmp_dir}/${sample}.norm.vcf.gz"

    #######################
    # Step 1: chr filter + normalize
    #######################
    bcftools view -r "$chr_list" "$raw_vcf" -Oz -o "${tmp_dir}/${sample}.chr.vcf.gz"
    bcftools norm -f "$REF" -m -both "${tmp_dir}/${sample}.chr.vcf.gz" -Oz -o "$norm_vcf"
    tabix -f -p vcf "$norm_vcf"

    #######################
    # Step 2: SNP / INDEL split
    #######################
    snp_vcf="${tmp_dir}/snp.vcf.gz"
    indel_vcf="${tmp_dir}/indel.vcf.gz"

    gatk SelectVariants -R "$REF" -V "$norm_vcf" -select-type SNP -O "$snp_vcf"
    gatk SelectVariants -R "$REF" -V "$norm_vcf" -select-type INDEL -O "$indel_vcf"

    #######################
    # Step 3: filtering
    #######################
    snp_f="${tmp_dir}/snp.f.vcf.gz"
    indel_f="${tmp_dir}/indel.f.vcf.gz"

    gatk VariantFiltration -R "$REF" -V "$snp_vcf" \
        -filter "QD < 2.0" --filter-name "QD2" \
        -filter "QUAL < 30.0" --filter-name "QUAL30" \
        -filter "SOR > 3.0" --filter-name "SOR3" \
        -filter "FS > 60.0" --filter-name "FS60" \
        -filter "MQ < 40.0" --filter-name "MQ40" \
        -filter "(vc.hasAttribute('MQRankSum') && MQRankSum < -12.5)" --filter-name "MQRS12.5" \
        -filter "(vc.hasAttribute('ReadPosRankSum') && ReadPosRankSum < -8.0)" --filter-name "RPRS8" \
        -O "$snp_f"

    gatk VariantFiltration -R "$REF" -V "$indel_vcf" \
        -filter "QD < 2.0" --filter-name "QD2" \
        -filter "QUAL < 30.0" --filter-name "QUAL30" \
        -filter "FS > 200.0" --filter-name "FS200" \
        -filter "(vc.hasAttribute('ReadPosRankSum') && ReadPosRankSum < -20.0)" --filter-name "RPRS20" \
        -O "$indel_f"

    #######################
    # Step 4: PASS + DP filter
    #######################
    snp_pass="${tmp_dir}/snp.pass.vcf.gz"
    indel_pass="${tmp_dir}/indel.pass.vcf.gz"

    bcftools view -f PASS -i 'FMT/DP[0]>10' "$snp_f" -Oz -o "$snp_pass"
    tabix -f -p vcf "$snp_pass"

    bcftools view -f PASS -i 'FMT/DP[0]>15' "$indel_f" -Oz -o "$indel_pass"
    tabix -f -p vcf "$indel_pass"

    #######################
    # Step 5: merge + final chr filter + output
    #######################
    merge_vcf="${tmp_dir}/merge.vcf.gz"

    bcftools concat -a "$snp_pass" "$indel_pass" -Oz -o "$merge_vcf"
    bcftools sort "$merge_vcf" -Oz -o "$pass_vcf"
    tabix -f -p vcf "$pass_vcf"

    rm -rf "$tmp_dir"

    echo "[INFO] Final VCF: $pass_vcf"
    echo "[INFO] Kept sites: $(bcftools view -H "$pass_vcf" | wc -l)"

done

2.2 Monopogen

Monopogen detects germline and somatic variants from single-cell sequencing data using haplotype phasing and linkage disequilibrium information from reference panels.

The workflow included:

  • Preprocessing: Prepare BAM files and genomic regions.
  • Germline calling: Identify variants using population reference panels.
  • Somatic calling: Detect cell-level somatic variants using the Monopogen workflow.

Reference: Monopogen (Nature Biotechnology, 2024)

import pysam
import pandas as pd
from collections import defaultdict
import gzip

def count_barcode_reads_from_bam(bam_path, barcodes_path, output_path):
    """
    Count reads associated with filtered cell barcodes from a BAM file.

    Parameters:
        bam_path: Path to the Cell Ranger BAM file.
        barcodes_path: Path to filtered barcodes.tsv.gz.
        output_path: Path to the output CSV file.
    """

    # 1. Load filtered barcodes
    with gzip.open(barcodes_path, 'rt') as f:
        filtered_barcodes = {line.strip().split('-')[0] for line in f}

    # 2. Initialize counters
    barcode_counter = defaultdict(int)
    total_reads = 0
    processed_reads = 0

    # 3. Iterate over BAM reads
    with pysam.AlignmentFile(bam_path, "rb") as bam:
        print(f"Processing BAM file: {bam_path}")

        for read in bam:
            total_reads += 1

            # Display progress
            if total_reads % 10_000_000 == 0:
                print(f"Processed {total_reads/1_000_000:.1f}M reads...")

            # Extract cell barcode
            if read.has_tag('CB'):
                cb = read.get_tag('CB').split('-')[0]

                # Count reads matching filtered barcodes
                if cb in filtered_barcodes:
                    barcode_counter[cb] += 1
                    processed_reads += 1

    # 4. Save results
    results = [
        {'barcode': bc, 'reads': count}
        for bc, count in barcode_counter.items()
    ]
    pd.DataFrame(results).to_csv(output_path, index=False)

    print(f"Completed! Total reads: {total_reads}")
    print(f"Matched filtered barcodes: {len(results)}")
    print(f"Output saved to: {output_path}")

for SAMPLE_DIR in "${SC_BASE}"/*; do

    [ -d "$SAMPLE_DIR" ] || continue

    sample=$(basename "$SAMPLE_DIR")

    germline_dir="${SAMPLE_DIR}/germline"

    if [[ ! -d "$germline_dir" ]]; then
        echo "[WARN] Skip ${sample}: germline directory not found"
        continue
    fi

    echo
    echo "===== Processing ${sample} ====="

    GL_ALL="${SC_BASE}/pool_filter/${sample}.gl.all.vcf.gz"
    PHASED_ALL="${SC_BASE}/pool_filter/${sample}.phased.all.vcf.gz"
    GL_PASS="${SC_BASE}/pool_filter/${sample}.gl.depth_pass.vcf.gz"
    KEEP_KEYS="${SC_BASE}/pool_filter/${sample}.keep.keys.txt"
    FINAL="${SC_BASE}/pool_filter/${sample}_PASS.vcf.gz"

    ####################################
    # Step1: concat all chromosomes
    ####################################

    bcftools concat -a -Oz -o "$GL_ALL" \
        $(find "$germline_dir" -maxdepth 1 -name "chr*.gl.vcf.gz" | sort -V)

    bcftools index -t "$GL_ALL"

    bcftools concat -a -Oz -o "$PHASED_ALL" \
        $(find "$germline_dir" -maxdepth 1 -name "chr*.phased.vcf.gz" | sort -V)

    bcftools index -t "$PHASED_ALL"

    echo "[INFO] concat finished"

    ####################################
    # Step2: depth filter on GL
    ####################################

    bcftools view -i '
        (TYPE="snp"  && INFO/DP>10) ||
        (TYPE!="snp" && INFO/DP>15)
    ' "$GL_ALL" \
      -Oz -o "$GL_PASS"

    bcftools index -t "$GL_PASS"

    ####################################
    # Step3: extract passing sites
    ####################################

    bcftools query \
        -f '%CHROM:%POS:%REF:%ALT\n' \
        "$GL_PASS" | sort -u > "$KEEP_KEYS"

    echo "[INFO] GL depth-pass sites: $(wc -l < "$KEEP_KEYS")"

    ####################################
    # Step4: filter phased VCF
    ####################################

    bcftools view \
        -T <(
            awk -F: 'BEGIN{OFS="\t"}{
                print $1,$2,$2,$3,$4
            }' "$KEEP_KEYS"
        ) \
        "$PHASED_ALL" | \
    bcftools view -i '
        GT!="0/0" &&
        GT!="0|0" &&
        GT!="./." &&
        GT!=".|."
    ' \
        -Oz -o "$FINAL"

    bcftools index -t "$FINAL"

    ####################################
    # Cleanup
    ####################################

    rm -f "$GL_ALL" "$GL_ALL.tbi"
    rm -f "$PHASED_ALL" "$PHASED_ALL.tbi"
    rm -f "$GL_PASS" "$GL_PASS.tbi"

    echo "[INFO] Final VCF: $FINAL"

parse_ref_alt_vec <- function(x) {
  x <- as.character(x)
  x[is.na(x) | x == "" | x == "."] <- "0/0"
  ref <- as.numeric(sub("/.*", "", x))
  alt <- as.numeric(sub(".*/", "", x))
  data.frame(ref = ref, alt = alt)
}

process_one_chr <- function(sample, chr) {
  message("Processing ", sample, " ", chr, " ...")
  BASE_DIR <- file.path(MONO_BASE, sample, "somatic")
  OUT_DIR  <- file.path(MONO_BASE, sample, "somatic_combine")
  dir.create(OUT_DIR, recursive = TRUE, showWarnings = FALSE)
  
  meta_file <- file.path(BASE_DIR, paste0(chr, ".putativeSNVs.csv"))
  mat_file  <- file.path(BASE_DIR, paste0(chr, ".SNV_mat.RDS"))
  
  if (!file.exists(meta_file)) {
    warning("Missing meta file: ", meta_file)
    return(NULL)
  }
  if (!file.exists(mat_file)) {
    warning("Missing mat file: ", mat_file)
    return(NULL)
  }
  
  meta <- fread(meta_file, data.table = FALSE)
  meta_filter <- meta %>%
    filter(
      Depth_total > 10,
      BAF_alt > 0.05,
      SVM_pos_score > 0.1
    )
  
  message(chr, " meta total: ", nrow(meta),
          " | after meta filter: ", nrow(meta_filter))
          
  snv_pass <- paste0(
    meta_filter$chr, ":",
    meta_filter$pos, ":",
    meta_filter$Ref_allele, ":",
    meta_filter$Alt_allele
  )
  
  mat <- readRDS(mat_file)
  cell_cols <- colnames(mat)[19:ncol(mat)]
  common_snv <- intersect(snv_pass, rownames(mat))
  message(chr, " overlap SNVs: ", length(common_snv))
  mat_sub <- mat[common_snv, cell_cols, drop = FALSE]
  
  variant_stat <- lapply(seq_len(nrow(mat_sub)), function(i) {
    x <- unlist(mat_sub[i, ], use.names = FALSE)
    pa <- parse_ref_alt_vec(x)
    
    data.frame(
      sample = sample,
      chr = chr,
      snv = rownames(mat_sub)[i],
      n_cells_with_any_reads = sum((pa$ref + pa$alt) > 0),
      n_cells_with_alt_reads = sum(pa$alt > 0),
      total_ref_reads = sum(pa$ref),
      total_alt_reads = sum(pa$alt),
      stringsAsFactors = FALSE
    )
  }) %>%
    bind_rows()
  
  variant_pass <- variant_stat %>%
    filter(
      n_cells_with_any_reads >= min_cells_with_any_reads,
      n_cells_with_alt_reads >= min_cells_with_alt_reads
    )
  
  message(chr, " after cell-level filter: ", nrow(variant_pass))
  message(chr, " cells: ", length(cell_cols))
  mat_pass <- mat_sub[variant_pass$snv, , drop = FALSE]
  
  cell_count <- sapply(cell_cols, function(cc) {
    x <- as.character(mat_pass[, cc])
    alt <- as.numeric(sub(".*/", "", x))
    alt[is.na(alt)] <- 0
    sum(alt > 0)
  })
  
  cell_count_df <- data.frame(
    sample = sample,
    chr = chr,
    cell = names(cell_count),
    n_variants = as.integer(cell_count),
    stringsAsFactors = FALSE
  )
  
  long_df <- lapply(seq_len(nrow(mat_pass)), function(i) {
    x <- as.character(mat_pass[i, ])
    pa <- parse_ref_alt_vec(x)
    
    data.frame(
      sample = sample,
      chr = chr,
      snv = rownames(mat_pass)[i],
      cell = colnames(mat_pass),
      ref_reads = pa$ref,
      alt_reads = pa$alt,
      stringsAsFactors = FALSE
    ) %>%
      filter(alt_reads > 0) %>%
      mutate(
        cell_id = paste0(sample, "_", cell),
        total_reads = ref_reads + alt_reads,
        baf_cell = alt_reads / total_reads
      )
  }) %>%
    bind_rows()
  
  rm(mat, mat_sub, mat_pass)
  gc()
  
  list(
    variant_stat = variant_stat,
    variant_pass = variant_pass,
    cell_count_df = cell_count_df,
    long_df = long_df
  )
}

2.5 scSNV

scSNV detects single-nucleotide variants from droplet-based scRNA-seq data using UMI consensus collapsing to reduce sequencing errors.

The workflow included:

  • Barcode counting: Identify cell barcodes from FASTQ files using a chemistry-specific barcode whitelist.
  • Read mapping: Align reads to the reference genome using scsnv map.
  • UMI collapsing: Collapse reads sharing the same UMI to reduce sequencing errors.
  • Cell identification: Identify valid cell barcodes using scsnvmisc cells.
  • Variant detection: Generate allele-specific pileups from collapsed reads.
  • Annotation: Annotate variants using population and RNA-editing reference databases.
  • Post-processing: Convert annotated results into sparse matrices using scsnv2mtx for downstream analysis.

10x chemistry settings:

  • 10x 3’ v2: -l V2, whitelist: 737K-august-2016.txt
  • 10x 3’ v3: -l V3, whitelist: 3M-february-2018.txt
  • 10x 5’ v2: -l V2_5P
  • 10x 5’ v3: -l V3_5P

Reference: scSNV (Genome Biology, 2021)

import os
import argparse
import numpy as np

from scipy.io import mmread

def main():
    parser = argparse.ArgumentParser(description="Extract filtered scSNV cell-mutation pairs and per-cell mutation counts.")
    parser.add_argument("--sample", required=True, help="Sample name, e.g. P5_cSCC")
    parser.add_argument("--indir", required=True, help="scSNV output directory")
    parser.add_argument("--outdir", required=True, help="Output directory")

    args = parser.parse_args()

    sample = args.sample
    indir = args.indir
    outdir = args.outdir
    os.makedirs(outdir, exist_ok=True)

    barcode_file = os.path.join(indir, "barcodes.txt")
    snv_file = os.path.join(indir, "snvs.csv")
    alt_file = os.path.join(indir, "alts.mtx")
    filtered_file = os.path.join(indir, args.filtered_csv)

    print(f"[INFO] sample: {sample}")
    print(f"[INFO] input dir: {indir}")

    # 1. Read cell barcodes and remove any trailing "-1" suffix
    barcodes = pd.read_csv(barcode_file, header=None, names=["cell"])
    barcodes["cell"] = barcodes["cell"].astype(str).str.replace("-1$", "", regex=True)
    barcodes["cell_index0"] = np.arange(barcodes.shape[0])
    print(f"[INFO] n_cells: {barcodes.shape[0]}")

    # 2. Read all SNV information; row indices in alts.mtx correspond to SNV row indices
    snvs = pd.read_csv(snv_file)
    snvs["snv_index0"] = np.arange(snvs.shape[0])
    snvs["mut"] = snvs["chrom"].astype(str) + ":" + snvs["pos"].astype(str) + ":" + snvs["ref"].astype(str) + ":" + snvs["alt"].astype(str)
    print(f"[INFO] n_all_snvs: {snvs.shape[0]}")

    # 3. Read the filtered SNV list for subsequent filtering by mutation ID
    filtered = pd.read_csv(filtered_file)
    filtered["mut"] = filtered["chrom"].astype(str) + ":" + filtered["pos"].astype(str) + ":" + filtered["ref"].astype(str) + ":" + filtered["alt"].astype(str)
    keep_mut = set(filtered["mut"])  # Convert mutation IDs to a set
    print(f"[INFO] n_filtered_snvs: {len(keep_mut)}")

    # 4. Read alts.mtx and retain cell-SNV records with alt_count > 0
    print("[INFO] reading alts.mtx ...")
    alt_mtx = mmread(alt_file).tocoo()
    print(f"[INFO] alt matrix shape: {alt_mtx.shape}")  # Verify matrix dimensions

    if alt_mtx.shape[0] != snvs.shape[0]:
        raise ValueError("Number of SNVs in alts.mtx does not match snvs.csv.")
    if alt_mtx.shape[1] != barcodes.shape[0]:
        raise ValueError("Number of cells in alts.mtx does not match barcodes.txt.")

    # Row index (SNV) | Column index (cell) | Value (alternative allele read count)
    df = pd.DataFrame({"snv_index0": alt_mtx.row.astype(np.int64), "cell_index0": alt_mtx.col.astype(np.int64), "alt_count": alt_mtx.data.astype(np.int32)})
    df = df[df["alt_count"] > 0].copy()
    print(f"[INFO] cell-SNV records with alt_count > 0 before filtering: {df.shape[0]}")

    # 5. Map matrix indices back to mutation IDs and cell barcodes
    df = df.merge(barcodes[["cell_index0", "cell"]], on="cell_index0", how="left")
    df = df.merge(snvs[["snv_index0", "mut"]], on="snv_index0", how="left")

    # 6. Retain mutations present in the filtered SNV list
    df = df[df["mut"].isin(keep_mut)].copy()
    print(f"[INFO] cell-SNV records after filtered SNV list: {df.shape[0]}")

    # 7. Export unique cell-mutation pairs
    cell_mut = df[["cell", "mut"]].drop_duplicates()
    out_cell_mut = os.path.join(outdir, f"{sample}_scSNV_filtered_cell_mut.tsv.gz")
    cell_mut.to_csv(out_cell_mut, sep="\t", index=False, compression="gzip")
    print(f"[INFO] saved cell-mut table: {out_cell_mut}")

    # 8. Count filtered mutations per cell, retaining cells with zero mutations
    cell_count = cell_mut.groupby("cell", as_index=False).agg(n_variants=("mut", "nunique"))
    all_cells = barcodes[["cell"]].copy()
    cell_count = all_cells.merge(cell_count, on="cell", how="left")
    cell_count["n_variants"] = cell_count["n_variants"].fillna(0).astype(int)
    cell_count.insert(0, "sample", sample)
    cell_count.insert(1, "tool", "scSNV")

    out_count = os.path.join(outdir, f"{sample}_scSNV_filtered_cell_variant_count.tsv")
    cell_count.to_csv(out_count, sep="\t", index=False)
    print(f"[INFO] saved cell count table: {out_count}")
    print("[DONE]")

def parse_info(info):
    d = {}
    for x in info.split(";"):
        if "=" in x:
            k, v = x.split("=", 1)
            d[k] = v
    return d

def get_pass_sites_from_base(base_vcf):
    """
    First-round filtering:
    - Chromosomes 1–22
    - INFO/DP > 10
    - INFO/AD / INFO/DP > 0.05
    """
    pass_sites = set()
    with gzip.open(base_vcf, "rt") as f:
        for line in f:
            if line.startswith("#"):
                continue
            arr = line.rstrip("\n").split("\t")
            chrom, pos, _id, ref, alt, qual, filt, info = arr[:8]
            if chrom not in set(map(str, range(1, 23))):
                continue
            info_d = parse_info(info)
            try:
                dp = int(info_d.get("DP", 0))
                ad = int(info_d.get("AD", 0))
            except ValueError:
                continue
            if dp <= 10:
                continue
            af = ad / dp if dp > 0 else 0
            if af <= 0.05:
                continue
            site_id = f"{chrom}:{pos}:{ref}:{alt}"
            pass_sites.add(site_id)
    return pass_sites

def count_cell_variants(sample):
    sample_dir = os.path.join(CELL_BASE, f"{sample}_1a")
    base_vcf = os.path.join(sample_dir, "cellSNP.base.vcf.gz")
    cell_vcf = os.path.join(sample_dir, "cellSNP.cells.vcf.gz")
    if not os.path.exists(base_vcf):
        print(f"[WARN] missing base VCF: {base_vcf}")
        return
    if not os.path.exists(cell_vcf):
        print(f"[WARN] missing cell VCF: {cell_vcf}")
        return
    print(f"\n===== {sample} =====")
    pass_sites = get_pass_sites_from_base(base_vcf)
    print(f"{sample}: first-round retained sites = {len(pass_sites)}")
    cell_barcodes = []
    cell_variant_count = defaultdict(int)
    cell_variant_ids = defaultdict(list)
    n_total_sites = 0
    n_round1_sites = 0
    n_round2_sites = 0
    with gzip.open(cell_vcf, "rt") as f:
        for line in f:
            line = line.rstrip("\n")
            if line.startswith("##"):
                continue
            if line.startswith("#CHROM"):
                header = line.split("\t")
                cell_barcodes = header[9:]
                continue
            arr = line.split("\t")
            n_total_sites += 1
            chrom, pos, _id, ref, alt = arr[0], arr[1], arr[2], arr[3], arr[4]
            if chrom not in set(map(str, range(1, 23))):
                continue
            site_id = f"{chrom}:{pos}:{ref}:{alt}"
            if site_id not in pass_sites:  # Count variants only at sites retained after first-round filtering
                continue
            n_round1_sites += 1

            fmt = arr[8].split(":")  # Determine the positions of GT, AD, and DP fields
            try:
                gt_idx = fmt.index("GT")
                ad_idx = fmt.index("AD")
                dp_idx = fmt.index("DP")
            except ValueError:
                continue
            sample_fields = arr[9:]
            cells_with_reads = 0
            cells_with_alt = 0
            alt_cells = []
            for i, g in enumerate(sample_fields):
                if g == "." or g.startswith(".:"):
                    continue
                parts = g.split(":")
                if len(parts) <= max(gt_idx, ad_idx, dp_idx):
                    continue  # Prevent incorrect indexing of GT, AD, and DP fields
                try:
                    gt = parts[gt_idx]
                    ad = int(parts[ad_idx])
                    dp = int(parts[dp_idx])
                except ValueError:
                    continue
                if dp > 0:
                    cells_with_reads += 1

                # Count a variant only when GT is not 0/0 and AD > 0
                if ad > 0 and gt not in {"0/0", "0|0", "./.", "."}:
                    cells_with_alt += 1
                    alt_cells.append(i)

            if cells_with_reads >= 5 and cells_with_alt >= 2:
                n_round2_sites += 1
                for i in alt_cells:
                    cell = cell_barcodes[i]
                    cell_variant_count[cell] += 1
                    cell_variant_ids[cell].append(site_id)

    out_file = os.path.join(
        OUT_BASE,
        f"{sample}_cellSNP_filtered_cell_variant_count.tsv"
    )
    with open(out_file, "w", newline="") as out:

        writer.writerow(["sample", "cell", "n_variants"])
        for cell in cell_barcodes:
            writer.writerow([
                sample,
                cell,
                cell_variant_count.get(cell, 0)

    with open(detail_file, "w", newline="") as out:
        writer = csv.writer(out, delimiter="\t")

            for variant_id in cell_variant_ids.get(cell, []):

    print(f"{sample}: final second-round sites = {n_round2_sites}")

2.9 SComatic

SComatic is a tool for detecting somatic mutations from single-cell RNA-seq and ATAC-seq data. It uses a beta-binomial statistical model to identify somatic variants across cell types without requiring matched normal samples.

The workflow included:

  • BAM splitting: Split BAM files by cell type using cell-type annotations.

  • Base counting: Count nucleotide support for each cell type.

  • Variant calling: Merge base counts and identify candidate somatic variants.

  • Filtering: Apply RNA-editing and panel-of-normals (PoN) filters.

  • Post-processing: Convert cell-type-specific TSV files into sorted and indexed VCF files for downstream evaluation.

Reference: SComatic (Nature Biotechnology, 2024)

scAllele detects SNVs, indels, and allele-specific splicing events from scRNA-seq data using local reassembly of expressed haplotypes.

The workflow included:

  • BAM splitting: Manually split scRNA-seq BAM files into individual cell-level BAM files.
  • Variant calling and filtering
  • Post-processing: Merge filtered variants across cells for downstream evaluation.
